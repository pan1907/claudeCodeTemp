# 松弛一刻 🌿

一个让你放松身心的轻量级网站：打开就能看到一段慢节奏的轻动画，底部可以切换不同场景。

## 场景

| 场景 | 描述 |
|------|------|
| 萤火 | 暗绿色的夜里，萤火虫缓缓漂浮、明灭呼吸 |
| 海浪 | 落日余晖下，几层海浪缓慢起伏 |
| 星夜 | 深蓝星空缓缓流转，偶尔划过一颗流星 |
| 呼吸 | 4-4-6 呼吸引导：跟着圆球吸气、屏息、呼气 |
| 落雪 | 雪花带着远近层次，安静地飘落 |

## 交互

- 点击底部按钮切换场景，也可以用键盘 ← → 键
- 鼠标静止 4 秒后，界面元素自动淡出，只留画面
- 手机端同样适配

## 怎么本地查看

整个网站只有一个 `index.html` 文件，无需安装任何东西——下载后用浏览器直接打开即可。

## 怎么发布上线（免费）

用 GitHub Pages 即可：

1. 打开仓库的 **Settings → Pages**
2. **Source** 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`
3. 保存后等一两分钟，页面会显示你的网址，类似 `https://<用户名>.github.io/<仓库名>/`

## 技术说明

纯前端单文件实现（HTML + CSS + Canvas 动画），零依赖、零后端、零成本。
