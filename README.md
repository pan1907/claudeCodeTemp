# 松弛一刻 🌿

一个让你放松身心的轻量级网站：打开就能看到一段慢节奏的轻动画，底部可以切换不同场景。

## 场景

每个场景都配有实时合成的环境音（右上角开关，默认关闭）：

| 场景 | 画面 | 声音 |
|------|------|------|
| 萤火 | 暗绿色的夜里，萤火虫缓缓漂浮、明灭呼吸 | 偶尔一声蟋蟀（脉冲成组的真实虫鸣，无底噪） |
| 海浪 | 几层海浪缓慢起伏，配色随当地时间在白天 / 黄昏 / 月夜间流转 | 轻柔的远景海面 + 每隔一阵一道近处拍岸；夜里更安静 |
| 星夜 | 整片星空绕天极极缓慢旋转，偶尔划过一颗流星；藏着北斗七星、仙后座、猎户座 | 近乎寂静，约一分钟才轻响一声高音风铃 |
| 呼吸 | 4-4-6 呼吸引导：跟着圆球吸气、屏息、呼气 | 无背景音，点一下敲一声木鱼 |
| 落雪 | 雪花缓缓飘落（偶有快雪），风时大时小、雪随之时密时疏并向风向偏移 | 清冷的风声，强度随雪势起伏 |
| 下雨 | 雨中绿庭：探入的枝叶随风摇曳框住画面，下方一池碧水有倒影、睡莲与涟漪，雨丝落到水面激起圈圈波纹 | 成片细碎的雨点为主体 + 一层很轻的高频沙沙 + 偶尔近处一滴；强度时大时小 |
| 昼夜 | 太阳月亮交替划过天空，天色、星星、山丘随之变化；白天偶有鸟群飞过；月亮呈现当天的真实月相 | 很轻的旷野风；有鸟群时才有鸟鸣 |
| 种地 | 一方稻田走过春种、夏长、秋收、冬藏（一年约 6 分钟），每季还有一次日落与黎明；屋边的苹果树按真实物候走过一年；农人春撒种、夏浇水、秋挥镰、冬天出门堆雪人；一只布偶猫白天在田里溜达、扑蝴蝶，入夜回家——冬天进屋睡、其他季节睡屋檐下；春夏有花蝴蝶飞进田里，冬雪时密时疏 | 田野的轻风；春夏秋白天有鸟鸣 |

## 点一点画面

每个场景都有应景的点击互动：

- **萤火**：点击处泛起微光，附近的萤火虫被吸引缓缓聚来
- **海浪**：一条海豚从海里缓缓跃出、划过一道弧线再入水，出入水处水珠飞溅、留下泡沫
- **星夜**：点空处召唤一颗流星；点星座附近，连线隐约浮现
- **呼吸**：泛起一圈光环（开声音时敲一声木鱼）
- **落雪**：一阵轻风把雪花吹开
- **下雨**：点池面溅起一圈圈扩散的涟漪；青蛙会自己隔一阵跳上一片睡莲叶（最多 3 只自动出现），也可点任意一片叶子主动唤来一只（可同时有多只），它正面朝你蹲着、约十秒鼓肚叫一声，过会儿跳回水里（出入水都溅起水花），再点它可提前请它下水
- **昼夜**：白天放飞一小群鸟，夜里点哪儿流星就从哪儿划过
- **种地**：点哪儿就种下一株新苗；秋天点成熟的庄稼可以亲手收割；春夏点击会引来一只蝴蝶（每只的颜色都是现场调出来的，最多 9 只）；冬天点苹果树，枝桠一抖、落下一蓬雪

## 随当地时间变化

- 打开网站时，按你的本地时间自动挑选场景：清晨/傍晚看「昼夜」（日出日落），白天看「海浪」，入夜看「萤火」，深夜看「星夜」
- 「昼夜」场景的起点对准你当地的真实时刻，再以约 15 分钟一天的速度缓缓循环；月亮形状按当天真实月相绘制
- 「海浪」的天色每一帧都跟着真实时钟走：挂机到傍晚，天色会自己暗下来，不打断、不切换

## 交互

- 点击底部按钮切换场景，也可以用键盘 ← → 键
- 右上角「♪ 声音」按钮开关环境音（全部由 Web Audio 实时合成，无音频文件）
- 鼠标静止 4 秒后，界面元素自动淡出，只留画面
- 手机端同样适配

## 怎么本地查看

整个网站只有一个 `index.html` 文件，无需安装任何东西——下载后用浏览器直接打开即可。

## 怎么发布上线（免费）

用 GitHub Pages 即可：

1. 打开仓库的 **Settings → Pages**
2. **Source** 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`
3. 保存后等一两分钟，页面会显示你的网址，类似 `https://<用户名>.github.io/<仓库名>/`

## 技术说明

纯前端单文件实现（HTML + CSS + Canvas 动画 + Web Audio 合成音效），零依赖、零后端、零成本。
